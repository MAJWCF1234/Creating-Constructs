Overgrown Construct

An original 32x32 overgrown concrete sandbox inspired by gm_construct, authored for Creating Constructs. Includes a courtyard, planted lawns, birch/pine canopy, ivy sheets, path lights, two water basins, a tall test block with face-mounted pipes (Share JSON), a low building, terrace stairs, roof gardens, an overhead bridge, basement gallery, tunnel and side chamber.

Open Saves and load Overgrown Construct. The save starts in first person at the courtyard entrance. Tab switches to the overview; Tab again returns to the saved entrance. The previous world is preserved in Before last load when you load it.

Files:
  Overgrown Construct.mns          — playable named save (walk spawn)
  Overgrown Construct Overview.mns — Blue-hour orbit for marketing / itch background
  Overgrown Construct.json         — Share-format backup (includes pipes)

Authoring: tools/make_overgrown_construct.py
Full World API (Share JSON, .mns, world.bin, pipes, piece IDs): docs/World-API.md
Itch background: tools/make_itch_background.py (from a native --capture of the Overview save)
