Overgrown Construct

An original 32x32 overgrown concrete sandbox inspired by gm_construct, authored for Creating Constructs. Includes a courtyard, planted lawn, two water basins, a tall test block, a low building, terrace stairs, roof gardens, an overhead bridge, basement gallery, tunnel and side chamber.

Open Saves and load Overgrown Construct. The save starts in first person at the courtyard entrance. Tab switches to the overview; Tab again returns to the saved entrance. The previous world is preserved in Before last load when you load it.

The .mns is a named save; the .json is an editable Share-format backup. tools/make_overgrown_construct.py is the reproducible authoring source.
